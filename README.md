## 🤯 What does it do??

It searches award space across **NINE** (yes, NINE 🔢) airline programs at once:

- 🍁 Aeroplan
- 🏔️ Alaska
- 🇯🇵 ANA
- 🐉 Cathay
- 🔺 Delta (we don't talk about the award chart 💀)
- 🇫🇷 Flying Blue
- 💙 JetBlue
- 🇸🇪 SAS
- 💋 Virgin

AND it has an **AI chat** 🤖💬 so you can literally just *vibe* your way to Business Class. "Find me lie-flat to Tokyo bestie" → 💺✨ done.

## 🏃‍♂️💨 Getting started (it's giving easy)

```sh
make tools   # 🛠️ summon the toolchain
make run     # 🔥 API + web, hot reload, no cap
make build   # 📦 ship it to prod (on a Friday 😈)
```

Or if you're a **container enjoyer** 🐳:

```sh
docker compose up
```

## 🧠 Tech stack (big brain only)

- 🐹 **Go** backend, because we're built different
- ⚛️ **React + Vite + Bun** frontend, blazingly fast™ 🔥
- 🤖 LLM chat, because it's 2026 and everything must be AI
- 🕷️ A headless browser, because airlines hate APIs and we hate airlines' APIs
